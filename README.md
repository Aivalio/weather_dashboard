# Weather Dashboard 🌤️

A Streamlit-based weather dashboard that fetches real-time data from the OpenWeatherMap API.
Built with OOP principles, caching, and unit testing.

## Features (planned)
- Current weather display
- 5-day forecast visualization
- Search history tracking
- Interactive map

## Tech Stack (planned)
- Python 3.11+
- Streamlit
- Requests
- Plotly
- Pytest
